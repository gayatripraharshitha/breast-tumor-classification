# Dataset

## Wisconsin Breast Cancer Original

This project uses the **Breast Cancer Wisconsin (Original)** dataset from the UCI Machine Learning Repository.

### Dataset information

- Dataset: Breast Cancer Wisconsin (Original)
- UCI dataset ID: 15
- Instances: 699
- Features: 9
- Target classes:
  - `2` — benign
  - `4` — malignant
- Missing values: present in `Bare_nuclei`

### Citation

Dua, D. and Graff, C. (2019).  
UCI Machine Learning Repository.  
University of California, Irvine, School of Information and Computer Sciences.

The dataset is accessed programmatically using the `ucimlrepo` package.

### Important note

The dataset should be obtained from the official UCI Machine Learning Repository rather than redistributed through this repository.

This project uses the dataset for educational and research-oriented machine-learning analysis.
